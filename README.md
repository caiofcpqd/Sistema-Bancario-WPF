# Sistema Bancário

Desenvolvimento de um sistema bancário simples em C# com WPF, com foco no aperfeiçoamento dos conhecimentos em programação e desenvolvimento de interfaces gráficas.

## Funcionalidades

* Transferências
* Pagamentos
* Extrato bancário
* Operações bancárias
* Interface gráfica utilizando WPF

## Tecnologias

* C#
* .NET
* WPF
* Visual Studio
